# Changelog

このパッケージの主な変更点を記録します。

## [1.1.0] - 2026-09-29

### Added

- unitypackage 一覧のボタンを、プロジェクトに入っている版との新旧で切り替えるようにした。現在の版は「開く」で、右端の下矢印から「再インポート」を選べる。現在の版より古い版は「再インポート」で、下矢印から「開く」を選べる。現在の版より新しい版と、まだインポートしていない unitypackage は「インポート」のみ。
- 「開く」は取り込み先のルートフォルダを Project ウィンドウで選択・ハイライトする。「再インポート」が収まるよう、ボタン全体の幅を広げた。

### Changed

- ウィンドウの内部構成を整理した(見た目と操作は変わらない)。
- Core 1.1.0 が必要。

## [1.0.0] - 2026-06-27
### Added
- 初回リリース。BLM ライブラリの閲覧・絞り込み・一括インポートを行うエディタウィンドウ。
